# Donate QR in PDF export — Design

**Date:** 2026-09-07
**Status:** Approved by user

## Objective

Add a donation QR code to the bottom of the last page of the PDF report export, so the
PDF itself becomes a donation channel when handed to a doctor or saved locally.
Update the donation link to the new CloudTips page.

## Scope

Included:
- New QR asset `src/assets/donate-qr.png` (already generated by user, decoded → `https://pay.cloudtips.ru/p/866cf60d`)
- `CLOUDTIPS_URL` updated to `https://pay.cloudtips.ru/p/866cf60d` (heart button + QR share one link)
- QR block drawn at the bottom of the last PDF page: QR ~90 pt, caption «Поддержать проект», URL text below
- If content already fills the bottom of the last page → new final page for the QR block
- Tests updated/added, `jsqr` devDependency removed (used only to verify the user's PNG)

Excluded:
- Redesign of PDF layout, headers/footers on every page, other donation surfaces
- Any async work in the export path (must remain synchronous — iOS share activation window)

## Design

### 1. Asset
`src/assets/donate-qr.png` — copy of user-provided `/Users/halapinvv/Downloads/qrCode (1).png`
(820×820, white background, alpha 255 everywhere, decoded content:
`https://pay.cloudtips.ru/p/866cf60d`).

### 2. Link
`src/constants.ts`: `CLOUDTIPS_URL = 'https://pay.cloudtips.ru/p/866cf60d'`.
Single source of truth — heart button and PDF QR both use it.

### 3. PDF (`src/logic/pdf-export.ts`)
- `import donateQr from '../assets/donate-qr.png?inline'` — data URI (same pattern as fonts).
- New internal function `drawDonateBlock(doc)` called at the end of `buildReportPdfBytes`:
  - QR size ≈ 90 pt, centered horizontally, at the bottom of the last page.
  - Caption «Поддержать проект» above the QR (PTSans, bold-ish ~10 pt, dark).
  - URL `CLOUDTIPS_URL` below the QR (PTSans ~7 pt, gray).
  - If content bottom (`lastAutoTable.finalY` / chart cursor) + block height exceeds
    `pageH − MARGIN` → `doc.addPage()` first, so the block never overlaps content.
- Export path stays fully synchronous.

### 4. Tests
- `src/logic/pdf-export.test.ts`: «includes donate QR block» — `byteLength` with QR > without.
- `src/components/ReportScreen.test.tsx`: expected CloudTips URL `e21e29f5` → `866cf60d`.
- `npm run test`, `tsc --noEmit`, `npm run build`.

## Risks

- Data-URI PNG in jsPDF `addImage` — used pattern is proven in codebase? (fonts use VFS,
  not `addImage`; fallback: decode base64 to bytes + `doc.addImage(dataUri, 'PNG', …)`).
  jsPDF supports PNG data URIs natively. Low risk.
- QR printed size must stay scannable: 90 pt ≈ 3.2 cm — well above the ~2 cm comfort threshold.

- `tsc --noEmit` clean, `npm run build` OK.
- Spot-check PDF bytes contain the QR image (size delta) — existing chart-test pattern.
