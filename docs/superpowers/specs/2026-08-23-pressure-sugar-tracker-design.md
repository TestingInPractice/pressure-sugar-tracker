# Дизайн: Трекер давления и сахара (PWA)

Дата: 2026-08-23
Статус: на рассмотрении пользователя

## 1. Обзор

Мобильное веб-приложение (PWA) для iPhone: пользователь создаёт настраиваемые отчёты
(например, «Давление и сахар»), заполняет их измерениями в виде таблицы, получает
напоминания о заполнении, архивирует отчёты и печатает их в PDF.

### Ключевые решения (согласованы с пользователем)

| Решение | Выбор |
|---|---|
| Платформа | PWA (веб-приложение) |
| Сохранность данных при удалении приложения | Ручные бэкапы: экспорт/импорт JSON-файла (без сервера) |
| Напоминания | .ics-событие в Календарь iPhone + внутренняя логика повторов до 3 раз |
| Рубильник на главном экране | Пауза всех внутренних напоминаний |
| Ширина столбца по умолчанию | 30 символов |
| Хостинг | GitHub Pages |
| Стек | React 18 + TypeScript + Vite + vite-plugin-pwa + Dexie (IndexedDB) |

## 2. Ограничения платформы (приняты осознанно)

- **Удаление PWA с домашнего экрана удаляет все локальные данные.** iCloud/CloudKit
  из веба недоступны. Компенсация: экспорт бэкапа вручную, импорт после переустановки.
- **Фоновые будильники в вебе отсутствуют.** Системное напоминание возможно только
  через Календарь iOS (.ics). Внутренние повторы работают, когда приложение открыто.
- Push-уведомления не используются (требуют сервера).

## 3. Экраны

```
┌───────────────────────────────┐
│ [Рубильник напоминаний вкл/выкл] │ ← глобальный, сохраняется
│───────────────────────────────│
│ Нижняя навигация:             │
│ Отчёты │ Архив │ Ещё          │
└───────────────────────────────┘
```

- **Отчёты** — список активных отчётов, кнопка «+ Добавить отчёт».
- **Архив** — список архивированных отчётов, кнопка «Разархивировать» у каждого.
- **Ещё** — экспорт/импорт бэкапа, инструкция по установке PWA на домашний экран.
- **Экран отчёта** — таблица записей + действия:
  - «+ Запись» — форма добавления измерения;
  - «Настроить поля» — конфигуратор полей;
  - «Напоминание» — настройка даты/времени и генерация .ics;
  - «Печать/PDF»; «Архивировать».
- Тап по записи — редактирование; удаление с подтверждением.

## 4. Модель данных

```ts
type FieldType = 'number' | 'text' | 'datetime';

interface Field {
  id: string;
  name: string;            // «Давление», «Примечание»…
  type: FieldType;
  unit?: string;           // размерность: «мм рт.ст.», «ммоль/л»
  required: boolean;
  width: number;           // ширина столбца в символах, дефолт 30
}

interface Reminder {
  enabled: boolean;
  datetime: string;        // ISO, дата+время следующего напоминания
}

interface Report {
  id: string;
  name: string;
  fields: Field[];         // 1..10, лимит хардкод MAX_FIELDS = 10
  archived: boolean;
  reminder?: Reminder;
  createdAt: number;
  updatedAt: number;
}

interface Entry {
  id: string;
  reportId: string;
  values: Record<string, string | number>; // fieldId → значение
  createdAt: number;
}

interface Settings {
  masterOn: boolean;       // рубильник напоминаний
}
```

Хранилище: IndexedDB через Dexie. Таблицы: `reports`, `entries`, `settings`.

Новый отчёт создаётся с шаблонным набором полей из ТЗ: номер (число),
дата и время (datetime, календарь), давление (число, мм рт.ст.),
сахар (число, ммоль/л), примечание (текст). Все поля редактируемы.

## 5. Конфигуратор полей и таблица

- До **10 полей** на отчёт (хардкод).
- Свойства поля: имя, тип (`number` / `text` / `datetime`), размерность,
  обязательность, ширина столбца (дефолт **30 символов**).
- `datetime` вводится нативным пикером `datetime-local` (календарь iOS).
- Валидация при сохранении записи: обязательные поля непустые; `number` — число.
- Таблица отчёта: фиксированные ширины столбцов (`ch` от `field.width`);
  длинный текст переносится вниз внутри ячейки (word-wrap), высота строки растёт.
- Число строк записей не ограничено.

## 6. Напоминания

- Настройка на каждом отчёте: вкл/выкл, дата + время.
- При включении приложение формирует **.ics** (событие + VALARM за 0 минут до времени)
  и предлагает сохранить/открыть → пользователь добавляет в Календарь iPhone.
  Будильник сработает системно даже при закрытом приложении.
- **Внутренние повторы:** когда приложение открыто, время наступило и после него
  нет новой записи в отчёте — показывается уведомление (Notification API).
  Игнорирование/отклонение → повтор. Максимум **3 повтора** (хардкод
  `MAX_REPEATS = 3`), интервал между повторами **10 минут**
  (`REPEAT_INTERVAL_MIN = 10`). После 3 повторов напоминание замолкает до
  внесения записи или перенастройки.
- Внесённая запись после срабатывания гасит активные повторы этого напоминания.
- **Рубильник OFF:** все внутренние напоминания всех отчётов молчат; новые .ics
  не предлагаются. Уже добавленные события в Календаре iOS приложение удалить
  не может (ограничение платформы) — фиксируется в подсказке интерфейса.

## 7. Хранение и бэкапы

- Всё локально в IndexedDB (Dexie). Сервера нет.
- **Экспорт:** один JSON-файл
  `{ version: 1, exportedAt, settings, reports: [{...report, entries: [...] }] }`
  → скачивание / системный шар → «Файлы» или iCloud Drive вручную.
- **Импорт:** выбор файла → проверка схемы (`version`) → предупреждение
  «текущие данные будут заменены» → полная замена.
- При первом запуске с пустой базой приложение предлагает «Импортировать бэкап?».
- Повреждённый/неверный файл → понятная ошибка, данные не трогаются.

## 8. Печать / PDF

- Кнопка «Печать» доступна для активных и архивных отчётов.
- Печатная вёрстка (`@media print`): заголовок = имя отчёта, колонки = поля
  (имя + размерность), строки = записи. Лишние интерактивные элементы скрыты.
- `window.print()` → системное меню Safari: AirPrint или «Сохранить как PDF».
- Если столбцов много, печать автоматически масштабируется по ширине листа.

## 9. Деплой и установка

- GitHub Pages, сборка Vite с настроенным `base`.
- `vite-plugin-pwa`: манифест (name «Трекер давления и сахара», standalone,
  иконки), service worker для офлайн-работы.
- Установка на iPhone: Safari → Поделиться → «На экран Домой». Уведомления
  внутри приложения доступны только у установленного PWA (iOS 16.4+); без
  установки приложение работает, но внутренние уведомления недоступны
  (календарные .ics работают всегда).

## 10. Ошибки и граничные случаи

- Отчёт без полей невозможен: минимум 1 поле, удаление последнего блокируется.
- Удаление поля отчёта: при сохранении конфигурации значения удалённого поля
  во всех записях отбрасываются (в таблице и на печати их больше нет).
- Импорт старой версии файла: отказ с сообщением обновить бэкап.
- Нет разрешения на уведомления: подсказка, напоминания продолжают работать
  внутри интерфейса (баннер на экране отчёта).

## 11. Тестирование

- Vitest, unit: логика повторов напоминаний, генерация .ics, экспорт/импорт
  (валидная схема, битый файл, чужая версия), валидация полей, лимит 10 полей.
- Ручной UAT на iPhone: установка PWA, создание отчёта, заполнение, .ics в
  календаре, печать в PDF, экспорт → удаление PWA → переустановка → импорт.

## 12. Не входит в объём (YAGNI)

- Серверная часть, push, авторизация, мультиустройственная синхронизация.
- Android-специфика (PWA останется кроссплатформенной по факту, но тестируем iOS).
- Графики/статистика измерений.
