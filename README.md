# 🩺 Трекер давления и сахара

Офлайн-PWA для ежедневного учёта артериального давления и уровня сахара. Работает без интернета и сервера: все данные хранятся только на вашем устройстве (IndexedDB).

**Живая версия:** https://testinginpractice.github.io/pressure-sugar-tracker/

---

## Возможности

- **Несколько отчётов** — каждый со своими настраиваемыми полями (до 10): число, текст, дата-время; настраиваемая ширина колонок
- **Таблица записей** с автонумерацией строк и редактированием на месте
- **Печать / PDF** — всей таблицы или за период «с–по» по полю «Дата и время» (в PDF попадает ровно то, что видно)
- **Напоминания** — уведомления браузера + события `.ics` для календаря
- **Нативный будильник** на iPhone через мост «Быстрых команд» (`shortcuts://`) — звонит как обычный будильник, даже если приложение закрыто
- **Экспорт / импорт бэкапа** — все отчёты одним JSON-файлом (вкладка «Ещё»)
- **Архив**, переименование, удаление отчётов с подтверждением
- **Тёмная тема** — автоматически по настройкам системы
- Полностью офлайн: service worker кэширует сборку, ставится на «Домой»

## Установка как приложение

**iPhone/iPad:** открыть ссылку в Safari → «Поделиться» → «На экран “Домой”».

**ПК (Chrome/Edge):** открыть ссылку → значок ⊕ в адресной строке → «Установить».

> Приложение полностью локальное: никаких аккаунтов, сети и отправки данных.

## Запуск на своём ПК

**Требования:** Node.js ≥ 20 ([nodejs.org](https://nodejs.org)), git.

```bash
git clone https://github.com/TestingInPractice/pressure-sugar-tracker.git
cd pressure-sugar-tracker
git checkout feature/app      # актуальная ветка разработки
npm install                   # установить зависимости
npm run dev                   # запустить дев-сервер
```

Откроется `http://localhost:5173`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер с горячей перезагрузкой (порт 5173) |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранной версии (порт 4173) |
| `npx vitest run` | Все тесты разово (82 шт.) |
| `npm test` | Тесты в watch-режиме |
| `npx tsc -b` | Только проверка типов |

## Деплой на GitHub Pages

Сборка настроена под путь `/pressure-sugar-tracker/` (`base` в `vite.config.ts`).

```bash
npm run build
# содержимое dist/ публикуется в ветку gh-pages,
# Pages: Settings → Pages → Deploy from branch → gh-pages / root
```

После обновлении сборки страница подхватит новую версию service worker'а после 1–2 перезагрузок.

## Структура проекта

```
src/
├── components/    # React-компоненты экранов (+ co-тесты *.test.tsx)
├── logic/         # чистые функции: форматирование, печать, бэкап, будильник…
├── db/db.ts       # слой хранения (Dexie / IndexedDB)
├── types.ts       # схема данных: Report, Entry, Field
└── index.css      # дизайн-токены и стили (light/dark, print)
```

## Технологии

React 19 · TypeScript 5.9 · Vite 6 · Dexie 4 (IndexedDB) · vite-plugin-pwa · Vitest 3 + Testing Library + fake-indexeddb

## Бэкапы

Вкладка **«Ещё» → «Экспорт бэкапа»** сохраняет все отчёты и записи в JSON-файл. **«Импорт бэкапа»** восстанавливает данные из файла (заменяет текущие). Храните файл в iCloud Drive / «Файлах» — после переустановки приложения данные вернутся за два нажатия.

---

Приватность: приложение не собирает и не отправляет никакие данные — вся история остаётся на устройстве.
